# Development brochures

One PDF per development, named after its slug in `app/lib/projects.ts` and
pointed at by that project's `brochure` field.

The files here are **placeholders**. Replace each one with the real brochure,
keeping the filename: the "Download Brochure" button emails a link to this
path, and a renamed file becomes a 404 in somebody's inbox.

A development with no brochure simply omits the `brochure` field — the button
is then absent rather than broken.
